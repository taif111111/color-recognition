# Color Recognition using OpenCV

## Project Description
This project detects four colors in real-time using a webcam and OpenCV.

## Features
- Detects Red
- Detects Green
- Detects Blue
- Detects Yellow
- Displays a bounding box and the detected color name

## Technologies Used
- Python
- OpenCV
- NumPy

## Requirements
- Python 3.x
- OpenCV
- NumPy

## Installation
pip install -r requirements.txt

## Run the Project
python main.py
